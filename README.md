# cost-band

Claude Code 입력창 위에 **비용과 대화 기억 공간**을 보여주는 밴드, 그리고 **"AI를 잘 쓰고 있나"** 를 일·주·월 단위로 평가해 주는 플러그인이에요. 화면과 평가 문구는 한국어예요.

- 비용이 얼마나 나오는지 매 답변마다 바로 보여요
- 대화가 너무 길어지기 전에 알려줘요 (여유 / 길어지는 중 / 새 대화 추천)
- 버튼 한 번으로 "저장 → 대화 초기화 → 이어받기"를 해요
- 이 컴퓨터의 사용 기록을 읽어서 사용 습관을 평가해 줘요

---

## 설치

터미널의 Claude Code에서:

```
/plugin install cost-band --marketplace jeonjuseong11/cost-band
```

셸에서:

```
claude plugin install cost-band --marketplace jeonjuseong11/cost-band
```

데스크톱 앱에서는 입력창 옆 **+ → Plugins → Add marketplace** 에 `jeonjuseong11/cost-band` 를 넣고 **Add plugin** 을 누르세요.

설치하면 `Add marketplace?` 질문에 `y`, 그다음 범위(scope)는 Enter로 고르면 돼요.

> 필요한 것: Claude Code, 그리고 평가 스킬용 **Python 3** (macOS에는 기본으로 있어요)

## 기능

### 1. 비용·기억 공간 밴드

입력창 위에 한 줄로 보여요. 접힌 상태는 숫자만 있어서 줄바꿈이 깨지지 않아요.

```
$0.91  방금 $0.91  기억 11% 사용 · 922.7k 남음  2m 57s  5시간 7% · 주간 10%            자세히
```

| 항목 | 뜻 |
|---|---|
| `$0.91` | 이번 대화에서 지금까지 쓴 돈 |
| `방금` | 직전 답변 하나에 든 돈 |
| `기억 11% 사용 · 922.7k 남음` | 대화 기억 공간을 얼마나 썼고 얼마 남았는지. 60%부터 노란색, 80%부터 빨간색 |
| `2m 57s` | AI가 일한 시간의 합 |
| `5시간 7% · 주간 10%` | 구독 한도 사용 비율 (구독 계정에서만 나와요) |

**자세히**를 누르면 맨 위 오른쪽에 `평가 · 정리하고 이어가기 · 접기` 버튼이 나오고, 아래에 4칸과 한도 줄이 한 격자로 펼쳐져요.

- **이번 대화 비용:** 지금까지 · 방금 · 답변 1번 평균
- **대화 기억 공간:** 사용 비율, 막대, 사용/남음
- **대화 진행:** 주고받은 횟수와 AI가 일한 시간
- **토큰 사용량:** AI가 읽은 양과 쓴 양
- **5시간 한도 · 주간 한도:** 한 줄에 반반씩. 사용 비율, 막대, 초기화까지 남은 시간이에요. 막대 위의 짧은 세로선(`|`)은 시간이 그만큼 지났다는 표시라서, 막대가 선보다 길면 시간에 비해 빨리 쓰고 있다는 뜻이에요. 이 속도면 초기화 전에 넘을 것 같거나 80%를 넘으면 노란색, 100%를 넘으면 빨간색으로 넘은 만큼 보여줘요. 정상일 땐 회색이에요.

> 대화 기억 공간이 가득 차면 AI가 오래된 대화를 잊거나 요약해요. 80%가 넘으면 새 대화를 여는 걸 추천해요.

### 2. 정리하고 이어가기 (인수인계)

대화가 길어졌을 때, 맥락을 잃지 않고 새 대화로 넘어가는 버튼이에요.

1. 버튼을 누르면 "저장하고 대화를 초기화해요. 계속할까요?"라고 한 번 확인해요 (`/clear`는 되돌릴 수 없어서요)
2. **저장:** Claude가 `~/.claude/handoffs/날짜-시각-세션.md`(예: `20261103-1530-a1b2c3d4.md`)에 인수인계 문서를 써요. 인수인계마다 새 파일이라 이전 문서를 덮어쓰지 않아요. 처음 요구와 바뀐 요구, 선호와 지적, 결정과 이유, 만든 파일, 아직 모르는 것, 남은 할 일, 원본 대화 기록 경로까지 담아요.
3. **초기화:** `/clear` 가 자동으로 실행돼요
4. **이어받기:** 문서를 읽고(애매한 부분은 원본 기록에서 찾아서) 목표 · 진행 상황 · 다음 할 일을 쉬운 말로 알려줘요

### 3. 일일 · 주간 · 월간 평가

`자세히`의 **평가** 버튼을 누르면 `일일 · 주간 · 월간`을 고르는 메뉴가 열려요. 하나를 고르면 그 평가가 채팅에 써져요. 직접 실행할 수도 있어요.

```
/cost-band:usage-review day
/cost-band:usage-review week
/cost-band:usage-review month
```

이 컴퓨터의 Claude Code 기록을 읽어서, 직전 같은 기간과 비교하며 다음을 평가해요.

- **총평:** 잘 쓰고 있어요 / 보통 / 손볼 곳이 있어요
- **잘한 점**과 **고치면 좋은 점** (근거 숫자와 바로 할 수 있는 행동 포함)
- 살펴보는 습관: 대화가 너무 길어지는지 · 같은 걸 다시 시키는 비율 · 요청이 얼마나 구체적인지 · 도구 실패 횟수 · 모델 선택

## 값은 어떻게 계산하나요?

### 밴드 (이번 대화)

| 값 | 계산 |
|---|---|
| 지금까지 비용 | Claude Code가 알려주는 세션 누적 비용을 매 턴 끝에 그대로 읽어요 |
| 방금 답변 | 이번 누적 비용 − 직전 턴 끝의 누적 비용 (`/clear` 직후에 누적이 줄면 누적 값 자체) |
| 답변 1번 평균 | 누적 비용 ÷ 주고받은 횟수 |
| 대화 기억 공간 % | Claude Code가 알려주는 컨텍스트 사용 비율을 그대로 사용 |
| 5시간 · 주간 한도 | Claude Code가 알려주는 구독 한도 사용 비율과 초기화 시각을 그대로 사용. 구독이 아니면 값이 없어서 표시하지 않아요 |
| 사용 / 남음 | 사용 = 컨텍스트 토큰 수 · 전체 = 사용 ÷ (퍼센트 ÷ 100) 로 역산 · 남음 = 전체 − 사용 |
| 주고받은 횟수 | 이 세션의 턴 수 |
| AI가 일한 시간 | 매 턴의 소요 시간의 합 |

서브에이전트가 쓴 토큰은 토큰 합계에만 더하고, 비용은 이미 세션 누적에 들어 있어서 따로 더하지 않아요.

### 평가 (이 컴퓨터 전체)

- 모든 세션 기록에서 AI 답변 1건마다 읽은 양 · 쓴 양 · 재사용 · 모델 · 시각을 모아요. 한 답변이 여러 줄로 나뉘어 있으면 마지막 한 줄만 세요.
- **기간:** 오늘, 최근 7일, 최근 30일을 각각 직전 같은 길이의 기간과 비교해요.
- **비용:** 이 플러그인이 남긴 턴별 기록(`~/.claude/cost-band-turns.csv`)을 합쳐요.
- **다시 시킨 비율:** 내 프롬프트 중 "아니, 다시, 별로, 말고, 틀렸, 이상, 왜, wrong" 같은 단어가 든 것의 비율
- **대화 길이:** 세션의 가장 큰 컨텍스트 토큰 수와 프롬프트 수
- **도구 실패:** 도구 호출 결과 중 오류로 표시된 횟수

## 개발과 검증

`claude plugin validate`는 통과하고, `claude plugin test`로 비용 계산과 한도 표시 테스트 2개가 돌아가요. 화면은 개발 중 직접 눈으로 확인하지 못한 부분이 있어요.

## 알아 둘 점 (한계)

- **비용(달러)은 이 플러그인을 켠 날부터만 정확해요.** 그 전 날은 토큰 양으로만 평가하고, 평가에도 그렇게 적혀요.
- **웹/폰 앱, 다른 컴퓨터의 사용량은 포함되지 않아요.** 이 컴퓨터의 Claude Code 기록만 읽어요.
- **"다시 시킨 비율"은 단어만 보는 어림값이에요.** 많이 틀릴 수 있으니 힌트로만 보세요.
- **여러 날에 걸친 긴 대화는** 마지막 메시지가 있는 날에 통째로 계산돼요.
- **한도 표시는 구독 계정에서만** 나오고, 마지막 API 응답 기준이에요. 한동안 질문이 없으면 이전 값이 보여요.
- **"남음"은 역산한 값이라** 반올림 오차가 있어요.
- "AI가 읽은 양"은 요금과 같은 비율로 오르지 않아서, 비용 비교용으로 쓰면 안 돼요.
- 인수인계의 `/clear` 자동 실행은 환경에 따라 안 될 수 있어요. 그러면 저장까지만 되고 빨간 안내가 떠요. 저장된 문서는 남으니 직접 `/clear` 하면 돼요.

## 개인정보

사용 기록은 모두 내 컴퓨터(`~/.claude`) 안에서만 읽고 써요. 어디로도 보내지 않아요. 인수인계 문서(`~/.claude/handoffs/` 안의 파일)에는 대화 내용이 들어가니 공유할 때 주의하세요.
